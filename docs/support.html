Common questions

NDI sources don't show up

Make sure your iPad and the NDI sender are on the same local network, and that WasteMix has Local Network access: Settings → Privacy & Security → Local Network → WasteMix. Some guest or venue Wi-Fi networks block device discovery; a dedicated router or wired network works best.

Other apps can't see WasteMix's NDI output

Turn on Program NDI in Advanced Output. The source appears on the network as “WasteMix Program”. Full-quality NDI uses a lot of bandwidth, so 5 GHz Wi-Fi or Ethernet (via a USB-C adapter) is recommended for 1080p.

Camera or microphone isn't working

Check Settings → WasteMix and make sure Camera and Microphone are allowed. The microphone is only used for audio-reactive visuals and is never recorded.

External display or projector

Connect over USB-C or an HDMI adapter. WasteMix sends program output fullscreen to the external display; use Advanced Output for slices, warping, and edge blending.
